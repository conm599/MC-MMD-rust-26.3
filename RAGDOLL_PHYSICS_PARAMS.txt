1. 单位与全局约定
--------------------------------------------------------------------------------
UNIT_TO_M（模型单位→米）          = 0.09        （Java 侧 MODEL_SCALE 同值 0.09）
空间约定                          骨骼右手 / 物理左手，边界用 inv_z 矩阵转换
独立 Bullet3 世界                 每具尸体一个，与 MMD 物理（头发衣物）互不干扰

11. 关节柔软度（ERP/CFM，由 joint_strength 推导）
--------------------------------------------------------------------------------
erp = clamp(0.25 × joint_strength, 0.1, 0.6)      （1.35 → ≈0.34）
cfm = clamp(0.02 / max(joint_strength, 0.1), 0.002, 0.05)
全部 6 轴同设（BT_CONSTRAINT_STOP_ERP / BT_CONSTRAINT_STOP_CFM）
线性限位全锁 ±0.001（锚点刚性）
弹簧全关（enable_spring(i,false) ×6）+ set_equilibrium_point()
（柔软感来自限位 ERP/CFM + 阻尼，弹簧会把姿势拽回绑定态——不要开）

--------------------------------------------------------------------------------
12. 碰撞体几何
--------------------------------------------------------------------------------
胶囊（常规段）:
 radius = r（第 7 节），capsule half_height = max(seg_len/2 - r, 0.004)
 capsule 全高 = max(capsule_half_height×2, 0.01)
 刚体中心 = 骨骼原点 + dir × (seg_len/2)；旋转 = from_rotation_arc(+Y, dir)
盒体（pelvis 退化 fallback：骨段长 < 0.03×radius_scale/0.09 时）:
 half = ( max(0.06×rs/0.09, gap×0.62), 0.07×rs/0.09, 0.09×rs/0.09 )
 gap = 左右大腿骨距离（fallback 0.22×rs/0.09）
all × thickness（clamp ≥0.1）

--------------------------------------------------------------------------------
13. 实测半径（measure_radii，优先于解剖学表）
--------------------------------------------------------------------------------
顶点到骨轴垂距的 0.85 分位数
clamp [0.018, 0.2] 米
命中判定：主导骨直接命中 16 段骨骼，或 twist/ツイスト/_jnt/ｊｎｔ 类辅助骨
沿父链上溯（≤32 跳）命中；muscleoffset / _offset 排除
输出米制后按第 7 节换算回模型单位

--------------------------------------------------------------------------------
14. 腿部自碰撞自动收缩（auto_fit_legs）
--------------------------------------------------------------------------------
触发：绑定姿态下双腿胶囊对（上/下腿 4 组合）间距 < r1+r2+margin(0.004)
动作：只缩大腿/小腿半径（不动脚），每轮 ×0.94，最多 18 轮
下限：0.45 × 基准半径；每轮同步 half_height = max(seg_len/2 - r, 0.004)

--------------------------------------------------------------------------------
15. 运行时安全钳制
--------------------------------------------------------------------------------
线速度上限 = 20.0 / 0.09 ≈ 222.2 模型单位/秒（超出按比例缩回）
角速度上限 = 25.0 rad/s
逃逸兜底（rescueEscaped）:
 位置 NaN / y < ground_y − 1.5/0.09×10 / |x|>700 / |z|>700
 → 重置到初始位姿 + 速度清零

--------------------------------------------------------------------------------
16. 模型更新管线集成顺序（runtime.rs，重写时顺序不能变）
--------------------------------------------------------------------------------
每帧 update 流程中布娃娃相关位置：
 1. animation_layer_manager.update / begin_animation
 2. reset_all_ik_enabled → 布娃娃激活时 set_all_ik_enabled(false)（防 IK 覆盖）
 3. 动画层 evaluate_normalized / VPD / 外部 IK / 眨眼 / 头部旋转 / morph
 4. ★ ragdoll.step(bones, elapsed)  —— 在 update_node_animation(false) 之前
    （接管骨被 update_transforms 跳过，从属骨由 pass 1 从新姿势传播）
 5. update_node_animation(false)
 6. VR IK：仅 ragdoll.is_none() 时执行
 7. MMD 物理（头发/衣物）：照常运行——FollowBone 刚体读到布娃娃姿势，自动跟随
 8. ★ 布娃娃激活时跳过 apply_transition_blend
    （矩阵过渡混合会向旧快照插值，与物理姿势冲突）
骨骼接管（bone_set.rs）:
 - ragdoll_bone_indices 持久集合（区别于每帧清空的 physics 集合）
 - update_transforms / update_global_transform_recursive 跳过接管骨
   （全局矩阵由布娃娃写入），子骨骼仍递归传播
 - update_non_physics_children(ragdoll_bone_indices)：D骨/足先EX/手指/饰品跟随
回写公式:
 bone_offset = body0⁻¹ × bone_left（构建时算好）
 每帧: bone_left_new = body_pose_left × bone_offset，再 inv_z 回写
       set_global_transform_physics(bone_index, inv_z(bone_left))
禁用布娃娃: disable_ragdoll → 拆 ragdoll → clear_ragdoll_bone_indices（骨骼交还动画）
